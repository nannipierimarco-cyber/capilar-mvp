PROMPT PARA CLAUDE CODE — MAPA CAPILAR

Objetivo:
Implementar en el flujo de Mapa Capilar un reporte visual descargable basado en análisis de IA, usando las respuestas iniciales del usuario + 2 fotos del pelo.

IMPORTANTE:
No quiero generar una imagen ahora.
Quiero implementar el flujo técnico en mi página para que, después de responder preguntas y subir fotos, el usuario vea un reporte capilar premium y pueda descargarlo.

Cambios requeridos:

1. Input del usuario
- Mantener las preguntas iniciales del flujo.
- En el último paso, exigir subida de 2 fotos:
  a) Foto frontal/lateral
  b) Foto desde arriba/coronilla
- No permitir continuar si falta una de las dos fotos.

2. Análisis IA
- Crear o ajustar el endpoint de análisis de Mapa Capilar.
- El endpoint debe recibir:
  - respuestas iniciales del usuario
  - foto frontal/lateral
  - foto coronilla
- La IA debe analizar las fotos usando también las respuestas del usuario como contexto obligatorio.
- El output de la IA debe ser JSON estructurado, no una imagen.

3. Qué debe analizar la IA
Evaluar:
- Tipo de pelo probable: liso, ondulado, rizado, afro/muy rizado
- Densidad capilar: baja, media, alta
- Estado de la línea capilar: estable, recesión leve, recesión moderada, recesión avanzada
- Visibilidad del cuero cabelludo
- Cobertura de coronilla
- Textura del pelo
- Grosor aparente del pelo
- Estado general del pelo
- Línea frontal
- Densidad frontal
- Recesión en entradas
- Coronilla
- Salud visible del cuero cabelludo
- Áreas de riesgo: entradas, zona frontal, zona media, coronilla

4. Secciones que NO deben aparecer en el reporte
Eliminar completamente:
- Rutina recomendada
- Guía de ingredientes
- Avoid overload
- Recomendaciones de productos
- Recomendaciones de shampoos
- Tratamientos recomendados
- Ingredientes recomendados
- Paso a paso de cuidado capilar

El reporte debe enfocarse solo en:
- Resumen general
- Contexto inicial del usuario
- Análisis visual
- Zonas capilares evaluadas
- Scores
- Áreas de riesgo
- Callouts sobre las fotos
- Disclaimer

Además de las imágenes, utiliza obligatoriamente las respuestas iniciales del usuario como contexto del análisis. Las respuestas del usuario deben influir en el resultado y también deben aparecer resumidas en el reporte final.

Objetivo:
Generar un análisis orientativo de pelo y cuero cabelludo con estilo de reporte premium de tricología/dermatología capilar.
