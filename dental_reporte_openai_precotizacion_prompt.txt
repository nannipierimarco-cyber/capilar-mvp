Necesito mejorar profundamente el output del reporte dental generado por OpenAI y la experiencia de subida de fotos.

Contexto:
El producto Dental Care cambió de foco. Ya no queremos que el reporte sea solo “análisis visual dental con IA”. Queremos que responda la pregunta principal del paciente:

“¿Qué parece verse en mis dientes, qué tratamiento podría necesitar evaluar y cuánto podría costar aproximadamente?”

El objetivo comercial es que el reporte entregue suficiente claridad para que el usuario quiera agendar una consulta y confirmar el presupuesto con un dentista.

Estado actual:
- El prompt actual es demasiado restrictivo.
- El system prompt prohíbe mencionar tratamientos como blanqueamiento, ortodoncia, carillas, implantes, cirugía, etc.
- Eso ya no sirve para el nuevo posicionamiento.
- El user prompt buildDentalUserPrompt todavía mapea campos del quiz antiguo de 8 preguntas.
- Con el quiz lean actual, los campos importantes son:
  - queQuieresResolver
  - prioridadUsuario
- El reporte actual no está suficientemente enfocado en posibles tratamientos y rangos de precio.
- La página de reporte debe mostrar arriba las fotos subidas por el usuario.
- La subida de fotos debe permitir tomar foto con cámara o subir desde galería.

Objetivo:
Actualizar el prompt, schema, procesamiento y UI para que el reporte dental sea una “orientación inicial + pre-cotización referencial”, sin hacer diagnóstico definitivo.

IMPORTANTE LEGAL/MÉDICO:
El reporte puede mencionar tratamientos posibles, pero siempre como:
- “opciones a evaluar”
- “posibles caminos”
- “tratamientos que un dentista podría revisar”
- “no confirmado solo con fotos”
- “requiere evaluación clínica”
- “los precios son referenciales”
No debe afirmar diagnóstico definitivo.
No debe prometer resultados.
No debe reemplazar evaluación odontológica.
Debe mencionar que luz, cámara, foco, ángulo y calidad de fotos pueden afectar la lectura visual.

Tareas:

1. Actualizar DENTAL_MAP_SYSTEM_PROMPT

Cambiar el enfoque actual.

Eliminar o reemplazar reglas que dicen:
- No recomiendes tratamientos específicos
- No mencionar blanqueamiento, ortodoncia, carillas, implantes, cirugía
- No elabores planes de tratamiento

Nueva lógica:
- Sí puede mencionar tratamientos dentales comunes como alternativas a evaluar.
- Puede mencionar:
  - limpieza / evaluación preventiva
  - blanqueamiento
  - resinas / restauraciones
  - ortodoncia
  - carillas / diseño de sonrisa
  - coronas / rehabilitación
  - implante dental
  - evaluación de encías
  - radiografía / scanner como examen necesario para confirmar
- Siempre debe hablar en modo preliminar:
  - “podría requerir evaluación para...”
  - “una opción a discutir con el dentista podría ser...”
  - “el rango referencial podría estar entre...”
- Debe evitar:
  - diagnóstico definitivo
  - urgencia médica definitiva
  - instrucciones clínicas
  - promesas de resultado
  - decir “necesitas X” de forma tajante

4. Rangos referenciales de precio

Incluir en el prompt estos rangos base para Chile, como referencias aproximadas:

- Limpieza / evaluación: $30.000 – $80.000
- Blanqueamiento: $80.000 – $250.000
- Resinas / restauraciones simples: $60.000 – $180.000 por pieza
- Ortodoncia tradicional / alineadores: $900.000 – $2.800.000
- Carillas / diseño de sonrisa: $1.200.000 – $4.000.000+
- Implante unitario: $600.000 – $1.500.000+
- Corona / rehabilitación: $300.000 – $900.000+
- Evaluación de encías / periodoncia inicial: $80.000 – $300.000+

Reglas:
- No inventar precisión falsa.
- Usar rangos amplios.
- Si la foto no permite inferir, decir que requiere evaluación.
- Puede sugerir combinación de tratamientos.
Ejemplo:
“Podrías evaluar una combinación de ortodoncia + blanqueamiento”
“Podrías requerir evaluación para restauración + corona, pero se necesita radiografía”
