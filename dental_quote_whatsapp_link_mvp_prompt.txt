Necesito implementar el MVP de subida de cotizaciones dentales externas y envío automático por WhatsApp a la clínica.

IMPORTANTE:
Vamos con la Opción A:
- NO mandar el PDF como archivo adjunto por WhatsApp.
- SÍ mandar un mensaje de WhatsApp con un link al documento subido.

Contexto:
Perfecto Labs tiene una sección dental donde los pacientes podrán subir cotizaciones/presupuestos que recibieron en otras clínicas.
Queremos que la clínica reciba automáticamente la información por WhatsApp para revisar y contactar al paciente.

Número WhatsApp clínica:
+56958043937

Flujo MVP:
1. Usuario completa formulario:
   - nombre
   - RUT
   - teléfono
   - email
   - archivo de cotización
   - tratamiento cotizado opcional
   - monto cotizado opcional
   - clínica donde cotizó opcional

2. El sistema:
   - valida los datos
   - sube el archivo a Supabase Storage
   - guarda registro en Supabase
   - genera link accesible al documento
   - manda WhatsApp a la clínica con datos + link
   - muestra success al usuario

2. Crear tabla Supabase
Crear SQL/migration para:

dental_quote_uploads

Campos:
- id uuid primary key default gen_random_uuid()
- full_name text not null
- rut text not null
- phone text not null
- email text not null
- treatment_type text null
- quoted_amount text null
- external_clinic_name text null
- file_url text not null
- file_path text not null
- original_file_name text null
- file_mime_type text null
- status text not null default 'submitted'
- whatsapp_sent_at timestamptz null
- whatsapp_error text null
- created_at timestamptz default now()
- updated_at timestamptz default now()

Status permitidos:
- submitted
- sent_to_clinic
- failed_to_send
- contacted
- won
- lost

Si el proyecto ya usa constraints/checks, agregar constraint.
Si el proyecto ya usa trigger updated_at, reutilizar patrón.

3. Supabase Storage
Crear o documentar bucket:
dental-quotes

Preferencia:
- bucket privado + signed URL si ya existe patrón en el proyecto.
- Si eso complica para MVP, usar bucket público temporalmente y dejar TODO claro para hacerlo privado después.

Ruta sugerida:
dental-quotes/{quoteId}/{safeFileName}

Tipos permitidos:
- application/pdf
- image/jpeg
- image/png
- image/webp

Tamaño máximo:
10MB

4. Crear endpoint backend
Crear endpoint:

POST /api/dental/quote-upload

Debe recibir multipart/form-data:
- fullName
- rut
- phone
- email
- treatmentType opcional
- quotedAmount opcional
- externalClinicName opcional
- consent
- file

Validaciones server-side:
- fullName requerido
- rut requerido
- phone requerido
- email requerido
- consent requerido
- file requerido
- tipo de archivo permitido
- tamaño máximo

Proceso:
A. generar quoteId
B. sanitizar nombre de archivo
C. subir archivo a Supabase Storage
D. generar fileUrl
E. insertar registro en dental_quote_uploads con status submitted
F. enviar WhatsApp a la clínica con fileUrl
G. si WhatsApp ok:
   - actualizar status = sent_to_clinic
   - whatsapp_sent_at = now()
H. si WhatsApp falla:
   - actualizar status = failed_to_send
   - whatsapp_error = error
I. responder JSON al frontend
