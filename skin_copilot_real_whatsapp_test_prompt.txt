Debe soportar:

GET:

  - hub.verify_token
  - hub.challenge
- Comparar hub.verify_token con process.env.WHATSAPP_VERIFY_TOKEN
- Si es correcto, responder hub.challenge
- Si es incorrecto, responder 403

POST:
- Recibir payload real de WhatsApp Cloud API.
- Parsear mensajes entrantes.
- Soportar al menos text messages.
- Extraer:
  - from / phone
  - message id
  - message text
  - timestamp
  - type
- Guardar inbound message si Supabase está configurado.
- Ejecutar Skin Copilot.
- Guardar outbound message si Supabase está configurado.
- Enviar respuesta por WhatsApp usando Cloud API.
- Responder 200 rápido a Meta para evitar retries.
