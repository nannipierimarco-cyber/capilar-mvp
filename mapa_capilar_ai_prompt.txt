Objetivo:
Agregar un nuevo flujo reducido de captación llamado “Mapa Capilar AI”.

Este flujo será usado desde una página externa:
https://perfectolabs.cl/salud-capilar

Ahí habrá un botón llamado “Mapa Capilar AI” que llevará a una nueva landing dentro de Nilo.

Ruta nueva sugerida:
`/mapa-capilar`

También crear páginas auxiliares si hace falta:

`/mapa-capilar/reporte`

El flujo debe ser independiente del quiz principal de Nilo.

====================================================
CONCEPTO
====================================================

Nombre del botón / producto:
“Mapa Capilar AI”

Subtítulo:
“Descubre visualmente tu situación capilar en menos de 2 minutos.”

El usuario responde 5 preguntas relevantes, sube obligatoriamente una foto de su pelo y luego ve una pantalla de espera con countdown mientras se genera un reporte visual orientativo con OpenAI.

Importante:
El reporte NO debe ser diagnóstico médico.
No debe recomendar productos.
No debe decir qué medicamentos usar.
No debe decir qué evitar.
No debe incluir shampoos, ingredientes, tratamientos específicos, minoxidil, dutasteride, finasteride ni recomendaciones terapéuticas.
Debe usar lenguaje prudente:
- “visual”
- “aparente”
- “orientativo”
- “según la imagen”
- “posible”
- “no reemplaza una evaluación médica”
- “requiere revisión profesional si quieres avanzar”

====================================================
FLUJO DEL USUARIO
====================================================

1. Usuario entra a `/mapa-capilar`
2. Ve una landing simple con el concepto “Mapa Capilar AI”
3. Responde 5 preguntas
4. Sube obligatoriamente una foto de su pelo
5. Va a una página de espera con countdown
6. El sistema genera un reporte visual orientativo
7. Para descargar/ver el reporte completo, el usuario debe completar sus datos
8. Al final debe indicar si está interesado en:
   - “Evaluar trasplante capilar”
   - “Soluciones para minimizar la caída”
   - “Solo quiero conocer mi situación capilar”

====================================================

Crear un mini-flow dentro de `/mapa-capilar`, o componentes internos, sin reutilizar de forma riesgosa el quiz principal.

Debe tener 5 preguntas:

- “Hermanos”
- “Abuelos”

Pregunta 5:
