Actúa como senior full-stack engineer en Next.js App Router, TypeScript, Supabase Storage y OpenAI Image Generation API.

Contexto:
Tengo un flujo dental en Perfecto Labs.
El usuario sube fotos dentales, completa un quiz y recibe un reporte en:
/dental/reporte/[id]

Problema:
El reporte web actual es demasiado genérico. Yo tengo un prompt visual que, cuando lo uso en ChatGPT, genera una infografía premium perfecta.
Quiero replicar ese resultado dentro de mi app.

Objetivo:
Agregar generación de una infografía dental visual premium como imagen PNG, usando el prompt visual original del usuario, y mostrarla en la página del reporte dental.

Importante:
No eliminar el análisis JSON actual todavía.
No romper el flujo dental existente.
No tocar HubSpot.
No tocar workflows.
No tocar appointments.
No tocar .env.local.
No tocar .claude/settings.local.json.

src/lib/dental/dentalInfographicPrompt.ts

- buildDentalInfographicPrompt()

El prompt debe usar exactamente el enfoque visual del prompt original:
- Infografía visual premium
- Análisis IA Dental y de Sonrisa
- Formato vertical tipo A4
- Fondo crema/off-white
- Bordes suaves
- Acentos dorados
- Branding Perfecto Labs

3. Crear endpoint server-side:
src/app/api/dental/infographic/route.ts

Debe:
- Recibir patientId/reportId
- Buscar las fotos asociadas al reporte
- Llamar a OpenAI Image Generation API con el prompt visual
- Generar una imagen vertical tipo A4
- Guardar la imagen en Supabase Storage
- Guardar la URL en Supabase asociada al reporte/paciente
- Devolver { success: true, infographicUrl }
